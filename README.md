# 📝 Todo List Manager

モダンなToDoリスト管理Webアプリケーションです。React、Tailwind CSS、IndexedDBを使用し、PWA対応でスマートフォンでも快適に使用できます。

## 🚀 機能

### タスク管理
- **ID**: タスクごとに自動採番
- **内容**: テキスト入力
- **優先度**: プルダウン選択（高・中・低・低め）
  - 高 = 赤
  - 中 = オレンジ  
  - 低 = 緑
  - 低め = 薄青
- **ABCD分類**: プルダウン選択
- **期限**: 日付入力（カレンダーUI）
- **見積時間**: 数値入力（時間単位）
- **実績時間**: 数値入力

### 進捗管理
- **チェックポイント**: 複数追加可能なサブタスク
- **進捗バー**: 完了数/全体数で進捗率を視覚化
- **完了チェック**: タスク全体の完了フラグ

### 表示ビュー
- **リスト表示**: タスク一覧（内容・期限・優先度・進捗バー表示）
- **フィルタ機能**: 「今日」「今週」「期限切れ」「未完了」など
- **ソート機能**: 「期限順」「優先度順」
- **カレンダー表示**: 月単位ビューでタスクを期日に表示

### インタラクション
- **優先度色分け**: 背景色で直感的に判別
- **期限色変化**:
  - 締切3日以上先 → 緑
  - 2日以内 → オレンジ
  - 当日 or 過ぎた → 赤
- **完了アニメーション**: タスク完了時に「🎉タスク完了！」表示

## 🛠 技術スタック

- **React** (最新推奨、Functional Componentベース)
- **Tailwind CSS** (スタイリング用)
- **IndexedDB** (タスクデータ保存、ブラウザ閉じても保持される)
- **React-Calendar** (カレンダー表示用)
- **PWA対応** (スマホで「ホーム画面に追加」可能)

## 🎨 デザイン

- シンプル＆モダンなTailwindベースのデザイン
- 各タスクはカード形式（丸角・シャドウあり）
- 優先度カラーを強調（赤は注意喚起的に目立たせる）
- ナビゲーションバーで「リストビュー ↔ カレンダービュー」切替
- スマホ対応（レスポンシブ）

## 📱 PWA対応

このアプリはPWA（Progressive Web App）として動作します：

1. スマートフォンのブラウザでアクセス
2. 「ホーム画面に追加」をタップ
3. アプリのように使用可能

## 🚀 使用方法

1. **タスクの作成**: 「タスク追加」ボタンをクリック
2. **タスクの編集**: タスクカードの「詳細を見る」をクリック
3. **進捗管理**: チェックポイントをチェックして進捗を更新
4. **ビュー切替**: ナビゲーションバーでリスト/カレンダーを切り替え
5. **フィルタ・ソート**: リストビューで条件に応じて表示を絞り込み
